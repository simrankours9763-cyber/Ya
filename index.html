Touch3D Studio

Build • inspect • rotate

1. Describe your object

A sample crystal lattice is ready. Drag it with your finger.

2. Add a picture or 3D model

A picture is a visual reference only; this starter version does not automatically convert a 2D picture into 3D. Import a GLB/GLTF/OBJ file to inspect a real 3D object.

3. Touch to explore

Drag to rotate • Pinch to zoom

Install on Android

This is an installable web-app project, not an APK. Upload this folder to an HTTPS web host, open its address in Chrome, then choose ⋮ → Install app or Add to Home screen. The app shell is cached for offline reopening. The 3D engine is loaded from a CDN, so the first launch and model import need internet access.
